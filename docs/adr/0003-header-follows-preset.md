# Page-header motion follows the Preset; site-header always persists

Named groups stay always-on (same classes, not a second catalog). The page header uses the site **Preset**; site-header stays `animation: none`.

Everstride staggers the header on its slide. That timing is a starting point, not a lock — **Preset** names stay, motion will be worked over. The decision is only: header is not a separately chosen animation.
