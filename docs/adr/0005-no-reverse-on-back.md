# Presets do not reverse on history back

Everstride always runs the same keyframes on link and back. Reverse-on-back was locked when this package was ClientRouter-shaped; it is out.

**Direction** is not a domain term. Preset names are catalog names; the actual motion will change. Do not encode reverse, stagger, or durations as product rules.

A Preset's **Origin** (`view-transition-from-*`) does not change this. It is one edge picked for the whole site, the same on link and back.
